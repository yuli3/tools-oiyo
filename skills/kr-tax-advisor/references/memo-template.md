# 상담 메모 형식

```
[주제] 비상장주식 평가 / 가업상속공제 / 법인전환 / DCF
[기준일] 2026-11-14 (계산 엔진 기준일) · 상담일 YYYY-MM-DD

1. 결론 (숫자 2~3개)
   - 예: 1주당 평가액 43,999원, 보유 60,000주 평가액 26.4억 원

2. 입력값과 가정
   - 사용자 제공: …
   - 가정(확인 필요): …

3. 계산 과정
   - 도구가 돌려준 단계를 그대로 옮긴다(숫자를 다시 계산하지 않음).

4. 근거 조문
   - 법 제○조, 시행령 제○조 …

5. 반영하지 않은 항목
   - 도구의 notCovered / 계산기 하단 안내를 그대로 옮긴다.

6. 확인할 요건 (체크리스트)
   - [ ] …

7. 다음 단계
   - 예: 감정평가 필요 여부, 평가심의위원회 심의, 사전 증여 검토, 세무사 검토
```

마지막 줄에 "실무 검토용 추정이며 세무대리·법률 자문이 아닙니다. 신고 전 원문 법령(law.go.kr)과 최신 해석을 확인하세요."를 넣는다.
