# 결정 메모 형식 (한 장)

```
[결정] 무엇을 정하나 (한 문장)
[틀] 고른 이론과 이유 (예: 의사결정 트리 — 결과가 불확실하고 선택지가 3개라서)
[기준일] YYYY-MM-DD

1. 결론
   - 추천: …  (핵심 숫자 2~3개: 기대값, 손실 확률 / 완료일, 핵심 경로 / LTV/CAC, 런웨이 …)

2. 근거
   - 도구가 돌려준 숫자를 그대로 옮긴다. 다시 계산하지 않는다.

3. 가정
   - 사용자 제공: …
   - 가정(확인 필요): … (누가, 언제까지 확인)

4. 결론이 바뀌는 조건
   - 예: "새 사업 성공 확률이 25%보다 낮으면 현상 유지가 낫다", "'비용' 가중치가 40%를 넘으면 1·2위가 바뀐다",
         "개발이 7일 늦으면 출시가 2일 밀린다", "이탈률이 9%를 넘으면 LTV/CAC가 3배 아래로 떨어진다"

5. 하지 말아야 할 것 / 위험
   - 손실 확률, 최악의 경우, 법·세무 의무(근거 조문)

6. 다음 행동
   - [ ] 할 일 — 담당 — 기한
```

마지막 줄: "판단을 돕는 참고 계산이며 법률·세무 자문이 아닙니다. 웹 도구에서 가정을 바꿔 확인해 보세요: <링크>"
